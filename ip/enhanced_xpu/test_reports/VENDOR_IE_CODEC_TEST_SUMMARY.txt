================================================================================
  MODULE ARCHITECTURE
================================================================================

TX MODE (mode = 0) - Encoding
────────────────────────────────────────────────────────────────────────────
Input:   25-byte Remote ID message (tx_remote_id_msg[199:0])
Output:  31-byte IEEE 802.11 Vendor IE (tx_ie_output[247:0])

IE Format (31 bytes):
  Byte [0]:     0xDD (Element ID - Vendor Specific)
  Byte [1]:     0x1D (Length - 29 bytes)
  Bytes [2-4]:  OUI (default 0x506F9A = WiFi Alliance)
  Byte [5]:     OUI Type (default 0x09 = Remote ID)
  Bytes [6-30]: 25-byte Remote ID payload

Latency: 2 clock cycles from start to valid output
Verification: valid=1, error=0 after operation complete

RX MODE (mode = 1) - Decoding
────────────────────────────────────────────────────────────────────────────
Input:   31-byte IEEE 802.11 Vendor IE (rx_ie_input[247:0])
Output:  25-byte Remote ID message (rx_remote_id_msg[199:0]) if valid

Validation Chain:
  1. Element ID check    → If ≠ 0xDD: error_code = 0x01 (ERR_INVALID_ID)
  2. Length check        → If ≠ 29:   error_code = 0x02 (ERR_INVALID_LENGTH)
  3. OUI check          → If mismatch: error_code = 0x03 (ERR_INVALID_OUI)
  4. OUI Type check     → If mismatch: error_code = 0x04 (ERR_INVALID_TYPE)

Result:
  - If all pass: valid=1, error=0, error_code=0x00, payload extracted
  - If any fail: valid=0, error=1, error_code=0xNN, early termination

Latency: 2 clock cycles from start to validation result
Throughput: 1 IE per 3 cycles maximum

CONFIGURATION
────────────────────────────────────────────────────────────────────────────
OUI/Type Override:
  oui_override = 0: Use DEFAULT_OUI (0x506F9A), DEFAULT_OUI_TYPE (0x09)
  oui_override = 1: Use oui_config[23:0], oui_type_config[7:0]

Applies to both TX and RX modes for consistent encode/decode
