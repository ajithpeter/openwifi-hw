FRAME FORMAT
────────────────────────────────────────────────────────────────────────────

WiFi Frame Layout:

┌────────────────────────────────────────────────────────────────────┐
│                                                                    │
│  MAC HEADER (24 bytes)                                            │
│  ├─ Frame Control (2)                                             │
│  ├─ Duration (2)                                                  │
│  ├─ Address 1-4 (18 + 2 padding)                                  │
│  └─ Sequence Control (2)                                          │
│                                                                    │
├────────────────────────────────────────────────────────────────────┤
│                                                                    │
│  NAN ACTION FRAME HEADER (7 bytes)                                │
│  ├─ Category: 0x7F (Vendor Specific)                              │
│  ├─ OUI: 0x50 0x6F 0x9A (WiFi Alliance)                           │
│  ├─ OUI Type: 0x13 (NAN)                                          │
│  ├─ OUI Subtype: 0x00                                             │
│  └─ Dialog Token (2 bytes)                                        │
│                                                                    │
├────────────────────────────────────────────────────────────────────┤
│                                                                    │
│  TLV ATTRIBUTES (variable length)                                 │
│                                                                    │
│  Attribute 1:                                                     │
│  ├─ Type (1 byte): 0x00 (Master Indication)                       │
│  ├─ Length (2 bytes, LE): variable                                │
│  └─ Value: ...                                                    │
│                                                                    │
│  Attribute 2:                                                     │
│  ├─ Type (1 byte): 0x03 ← SERVICE DESCRIPTOR                      │
│  ├─ Length (2 bytes, LE): 11 + payload_len                        │
│  └─ Value:                                                        │
│     ├─ Service ID (6 bytes): 0x88 0x69 0x19 0x9D 0x92 0x09       │
│     ├─ Instance ID (1)                                            │
│     ├─ Requestor Instance ID (1)                                  │
│     ├─ Service Control (1)                                        │
│     ├─ Binding Bitmap (1)                                         │
│     ├─ Service Info Length (1): MUST BE 25 for Remote ID          │
│     └─ Service Info (25 bytes): ← REMOTE ID PAYLOAD               │
│        ├─ Message Type (1): 0x00=Basic, 0x01=Location, etc.       │
│        └─ Message Data (24 bytes): ASTM F3411-22 payload          │
│                                                                    │
│  ... more attributes ...                                          │
│                                                                    │
└────────────────────────────────────────────────────────────────────┘

                              Frame Bytes:
           ┌──────────────────────────────────────────┐
           │ 0          1         2         3        │
           │ 0123456789ABCDEF0123456789ABCDEF0123456 │
           ├──────────────────────────────────────────┤
      Byte │ ........... MAC (24) ...........         │
       0-23│ ......... SKIP_HEADERS state ..........   │
      Byte │ FCDUUUUUUUOOINTSDT                      │
      24-30│ ... ACTION HEADER (7) ...                │
           ├──────────────────────────────────────────┤
      Byte │ ATTYPLENLENVAL..................          │
      31-33│ ATTR_TYPE → ATTR_LEN_LOW → ATTR_LEN_HIGH │
           ├──────────────────────────────────────────┤
      Byte │ IIIIIIIINSRCCTLBDRSIIIIII(24 more)       │
      34-69│ ← SERVICE DESCRIPTOR (36 bytes) ────→    │
           │ SVC_DESC_ID(6) + HDR(5) + REMOTE_ID(25) │
           └──────────────────────────────────────────┘

Case statement (should execute):
  ST_ATTR_TYPE:
      if (byte_counter >= pkt_length - 3)
          next_state = ST_COMPLETE;  ← Should complete here
      else if (pkt_eof)
          next_state = ST_COMPLETE;  ← Or complete here

EOF override (AFTER case statement):
  if (pkt_eof && state != ST_REMOTE_ID_DATA &&

TIMING DIAGRAM - SERVICE ID BUG
────────────────────────────────────────────────────────────────────────────

Input bytes (correct):
  [0x88, 0x69, 0x19, 0x9D, 0x92, 0x09]

Clock timeline:

  Clk    Byte  Operation                  service_id_buffer Result
  ──────────────────────────────────────────────────────────────────
  1      0x88  buffer <= {0x88, 0}        48'h00000000_0088  ✓
  2      0x69  buffer <= {0x69, 0}        48'h00000000_6900  ✗
  3      0x19  buffer <= {0x19, 0x69}     48'h00000001_9690  ✗
  4      0x9D  buffer <= {0x9D, 0x19}     48'h00000019_9XXX  ✗
  5      0x92  buffer <= {0x92, 0x9D}     48'h000019_9DXXXX  ✗
  6      0x09  buffer <= {0x09, 0x92}     48'h0019_9D92XXXX  ✗
         
         Comparison:
         {0x09, buffer[47:8]} = {0x09, 0x19_9D92XX}
                              = 0x0919_9D92XXXX
         
         Expected:  0x886919_9D9209
         Got:       0x0919_9D92XXXX
         Match: FALSE ✗

Correct implementation (left shift, MSB entry):

  Clk    Byte  Operation              service_id_buffer Result
  ──────────────────────────────────────────────────────────────────
  1      0x88  buffer <= 0x88 << 40   48'h88_0000_0000  ✓
  2      0x69  buffer <= {buf[39:0],0x69} 48'h00_0000_0069  ✗ (still wrong)

Actually, correct method is array-based:

  Clk    Byte  Operation                    
  ──────────────────────────────────────────────────────────────────
  1      0x88  bytes[0] <= 0x88
  2      0x69  bytes[1] <= 0x69
  3      0x19  bytes[2] <= 0x19
  4      0x9D  bytes[3] <= 0x9D
  5      0x92  bytes[4] <= 0x92
  6      0x09  bytes[5] <= 0x09
         
         Assemble: {bytes[0], bytes[1], bytes[2], bytes[3], bytes[4], bytes[5]}
                 = {0x88, 0x69, 0x19, 0x9D, 0x92, 0x09}
                 = 48'h886919_9D9209 ✓
         
         Comparison: 48'h886919_9D9209 == 48'h886919_9D9209 ✓
         Match: TRUE ✓
