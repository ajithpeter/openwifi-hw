STATE MACHINE ANALYSIS
================================================================================

States Defined: 12 (but documentation says 11)
  ST_IDLE (0)       → Wait for frame start
  ST_SKIP_HEADERS   → Skip 31 bytes MAC+Action header
  ST_ATTR_TYPE      → Read TLV attribute type
  ST_ATTR_LEN_LOW   → Read TLV length low byte
  ST_ATTR_LEN_HIGH  → Read TLV length high byte
  ST_ATTR_VALUE (5) → *** UNUSED - NEVER ENTERED ***
  ST_SVC_DESC_ID    → Read 6-byte service ID
  ST_SVC_DESC_HDR   → Parse service descriptor header
  ST_REMOTE_ID_DATA → Extract 25-byte Remote ID payload
  ST_SKIP_ATTR      → Skip non-matching attributes
  ST_COMPLETE       → Parsing complete
  ST_ERROR          → Error state

All states reachable: YES (except State 5)
Reset behavior: CORRECT
EOF handling: BROKEN (Bug #2)
